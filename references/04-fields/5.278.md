# 5.278 Activity Type

> 定义于 424-19 424-20 424-21 424-22 424-23 ｜ 缺失于 424-18

**用于：** 4.1.33.1 列 7（SAA Type）

## 定义

Definition/Description: The Activity Type is used to define the type of Special Activity that is
occurring.

Source/Content: The Activity Type should be derived from official government publications. Used
On: Special Activity Area records

Length: 1 character

Character Type: Alpha

## 正文表格

（424-23 第 305 页）

| Type Field | Content |
|---|---|
| Parachute Jumping Area | P |
| Glider Operations | G |
| Hang Glider Activities | H |
| Ultralight Activities | U |
