# 5.59 Runway Description

> 缩写 `RUNWAY DESCRIPTION` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.10.1 列 102（Runway Description）

## 定义

Definition/Description: If required, additional information concerning a runway can be included
in a record in the Runway Description field.

Source/Content: Appropriate contents for the field will be determined when the record is
assembled. Used On: Runway records

Length: 22 characters max

Character Type: Alpha/numeric Examples: GROOVED, SINGLE ENG. ONLY
