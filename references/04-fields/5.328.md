# 5.328 Initial Domain Identifier

> 定义于 424-23 ｜ 缺失于 424-18 424-19 424-20 424-21 424-22

**用于：** 4.1.37.1 列 22（Initial Domain Identifier）

## 定义

Definition/Description: The Initial Domain Identifier is required by ISO/IEC 8348 as an element
of the IDP and is also part of the ISO/IEC 10589 Area Address.

Source/Content: The field will be coded from either State publication or from ICAO
documentation. Used On: ATN Data Code Primary Records

Length: 4 characters
