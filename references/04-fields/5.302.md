# 5.302 Surface Type

> 定义于 424-21 424-22 424-23 ｜ 缺失于 424-18 424-19 424-20

**用于：** 4.1.10.2 列 93（Runway Surface Type）；4.1.36.1 列 53（Helipad Surface Type）；4.2.9.1 列 53（Helipad Surface Type）

## 定义

Definition/Description: The Surface Type field defines the predominant surface type of the
runway/helipad described in the record.

Source/Content: Valid contents are defined in column 1 of the table below. Column 3 defines the
Runway Surface Code that must be associated for each Runway Surface Type. Used On: Runway
Continuation, Airport Helipad, Heliport Helipad Records

Length: 4 Character

Character Type: Alpha
