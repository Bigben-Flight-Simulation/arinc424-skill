# 5.262 Approach Type Identifier

> 缩写 `ATI` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.28.2 列 47（Approach Type Identifier）；4.1.35.2 列 47（Approach Type Identifier）；4.2.8.2 列 47（Approach Type Identifier）

## 定义

Definition/Description: Identifies the approach types published on a given approach procedure
which require Airport or Helicopter Operations SBAS Path Points records.

Source/Content: Up to 10 characters representing the literal name of an approach with vertical
guidance requiring path points, Horizontal Alert Limit (HAL) and Vertical Alert Limit (VAL). The
name is derived from government source material. Used On: Airport and Helicopter Operations SBAS
Path Point Continuation Records

Length: 10 Characters

Character Type: Alpha/numeric Examples: LPV, LP, APV-II
