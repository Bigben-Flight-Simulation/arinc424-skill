# 5.255 SBAS Service Provider Identifier

> 缩写 `SBAS ID` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.28.1 列 29（SBAS Service Provider Identifier）；4.1.35.1 列 29（SBAS Service Provider）；4.2.8.1 列 29（SBAS Service Provider Identifier）

## 定义

Definition/Description: The SBAS Service Provider Identifier field is used to associate the SBAS
approach procedure to a particular satellite-based approach system service provider. The SBAS
Service Provider is carried in the GBAS Path Point Record only for the purpose of CRC
calculations.

Source/Content: A number from 00 to 15. The current definitions are: Used On: Airport and
Helicopter Operations SBAS Path Point Records, GBAS Path Point Records

Length: 2 characters

Character Type: Numeric

## 正文表格

（424-23 第 295 页）

| 0 | WAAS |
|---|---|
| 1 | EGNOS |
| 2 | MSAS |
| 3 | GAGAN |
| 4 | SDCM |
| 5-13 | (Spare) |
| 14 Not intended for SBAS, used as the CRC default value for | GBAS |
| 15 Any Service provider may be | used |
