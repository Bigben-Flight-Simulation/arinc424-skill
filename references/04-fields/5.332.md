# 5.332 Administrative Region Selector

> 缩写 `ARS` ｜ 定义于 424-23 ｜ 缺失于 424-18 424-19 424-20 424-21 424-22

**用于：** 4.1.37.1 列 36（Administrative Region Selector）

## 定义

Definition/Description: In Fixed Network Addressing Domains, the purpose of the ARS field is to
distinguish Routing Domains or Routing Domains and subordinated Routing Areas respectively
operated by the same State, airline, or Organization. In Mobile Network Addressing Domain, the
purpose of the ARS field is to identify the aircraft on which the addressed system is located.
When the systems onboard an aircraft form a single Routing Domain, then the ARS field also
identifies the Routing Domain. When the systems onboard an aircraft form multiple Routing
Domains, then part of the LOC field is used to distinguish them.

Source/Content: The field will be coded from either State publication or from ICAO
documentation. Used On: ATN Data Code Primary Records

Length: 6 characters

Character Type: Alpha/numeric Examples: 01534E
