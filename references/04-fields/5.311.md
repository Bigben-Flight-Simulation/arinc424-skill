# 5.311 FIR/FRA Transition

> 定义于 424-21 424-22 424-23 ｜ 缺失于 424-18 424-19 424-20

**用于：** 4.1.2.4 列 44（FIR/FRA Entry Point）；4.1.2.4 列 45（FIR/FRA Exit Point）；4.1.2.4 列 46（FRA Arrival Transition Point）；4.1.2.4 列 47（FRA Departure Transition Point）；4.1.2.4 列 48（FRA Intermediate Point）；4.1.2.4 列 49（FRA Terminal Holding Point）；4.1.3.4 列 44（FIR/FRA Entry Point）；4.1.3.4 列 45（FIR/FRA Exit Point）；4.1.3.4 列 46（FRA Arrival Transition Point）；4.1.3.4 列 47（FRA Departure Transition Point）；4.1.3.4 列 48（FRA Intermediate Point）；4.1.3.4 列 49（FRA Terminal Holding Point）；4.1.4.3 列 44（FIR/FRA Entry Point）；4.1.4.3 列 45（FIR/FRA Exit Point） 等 18 处

## 定义

Definition/Description: The Flight Information Region (FIR) Free Route Airspace (FRA) columns
allow designation of specific types used to enter, exit, and/or transition through FRA areas.
These designations will normally be provided by host nation authorities via their AIP.

Source/Content: The field content will be derived from official government sources. The content
will be selected from the table below. multiple values There may be assigned by the State
airspace authority. Used On: Waypoint, Flight VHF NAVAID, and NDB NAVAID Flight Planning
Continuation Records

Length: 1 Character

Character Type: Alpha/numeric
