# 5.18 Boundary Code

> 缩写 `BDY CODE` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.6.1 列 44（Boundary Code）

## 定义

Definition/Description: Routes of flight frequently cross geographical boundaries. The Boundary
Code field identifies the area into, or from which a continuous route passes when such a
crossing occurs.

Source/Content: See

Table 5-17. Used On: Enroute Airways records

Length: 1 character

Character Type: Alpha/numeric
