# 5.303 Helipad Shape

> 定义于 424-21 424-22 424-23 ｜ 缺失于 424-18 424-19 424-20

**用于：** 4.1.36.1 列 23（Helipad Shape）；4.2.9.1 列 23（Helipad Shape）

## 定义

Definition/Description: The Helipad Shape field defines the geometric shape of a helipad as
being either circle, runway, or rectangular.

Source/Content: The field contains the shape of the helipad derived from official government
sources when available. The content will be selected from the table below: Used On: Airport
Helipad Records, Heliport Helipad Records

Length: 1 Character

Character Type: Alpha

## 正文表格

（424-23 第 315 页）

| Field Content Description |
|---|
| C | Circle |
| S Square/Rectangle |
| R | Runway |
| U Undefined, helipad shape not provided in | source |
