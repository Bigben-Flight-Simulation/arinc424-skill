# 5.125 FIR/UIR Name

> 定义于 424-19 424-20 424-21 424-22 424-23 ｜ 缺失于 424-18

**用于：** 4.1.17.1 列 99（FIR/UIR Name）；4.1.37.1 列 65（FIR/UIR Name）

## 定义

Definition/Description: The FIR/UIR Name field contains the official name of the controlling
agency of the FIR/UIR of which this record is an element.

Source/Content: The FIR/UIR name will be derived from official publications. The areas without a
specific FIR/UIR designation will be labelled NO FIR. The FIR/UIR name will be derived from
either State publication or from ICAO documentation when used on ATN DATA records. Used On:
FIR/UIR and ATN Data records

Length: 25 characters

Character Type: Alpha/numeric Examples: ACCRA, FIR, ASUNCION FIR/UIR, NO FIR, DNEPROPETROVSK
