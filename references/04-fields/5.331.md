# 5.331 Routing Domain Format

> 缩写 `RDF` ｜ 定义于 424-23 ｜ 缺失于 424-18 424-19 424-20 424-21 424-22

**用于：** 4.1.37.1 列 34（Routing Domain Format）

## 定义

Definition/Description: There is no absolute requirement for the remainder of the DSP in each of
the above defined Network Addressing Domains to be allocated according to a coordinated
addressing plan, or for even the same fields to exist, or the NSAP Addresses to have the same
length. However, to encourage common equipment development, the existence, size and use of the
RDF, ARS, and LOC fields are specified hereunder. The reason for the existence of the RDF field
is historical.

Source/Content: The field will be coded from either State publication or from ICAO
documentation. Typically, the field is set to 00. Used On: ATN Data Code Primary Records

Length: 2 characters
