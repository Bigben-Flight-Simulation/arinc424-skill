# 5.337 Use Indicator

> 定义于 424-23 ｜ 缺失于 424-18 424-19 424-20 424-21 424-22

**用于：** 4.1.37.1 列 64（Use Indicator）

## 定义

Definition/Description: The use indicator field indicates the status of an ATN ATSU Ground
Facility, whether it is implemented, future or planned implementation, included for testing, or
a blank for unknown.

Source/Content: The content will be selected from the following table: Used On: ATN Data Code
Primary Records

Length: 1 character

Character Type: Alpha/numeric

## 正文表格

（424-23 第 327 页）

| Use Field | Content |
|---|---|
| Implemented | Y |
| Future | N |
| Test Facility | T |
| Unknown | Blank |
