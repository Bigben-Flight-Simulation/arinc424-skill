# 5.219 Geographical Entity

> 缩写 `GEO ENT` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.26.1 列 10（Geographical Entity）

## 定义

Definition/Description: The Geographical Reference Table will be used to identify Geographical
Entities not definable by other established encoding systems. For established systems refer to
Section 7 of this document.

Source/Content: The content of the field will be derived from official government source
documentation for preferred route systems of any kind. Used On: Geographical Reference Table
Records

Length: 29 characters

Character Type: Alpha/numeric
