# 5.135 Course FROM/TO

> 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.16.1 列 29（Course From）；4.1.16.1 列 33（Course To）

## 定义

Definition/Description: The Course From field is used to indicate the lowest course for which a
block of cruising levels is prescribed. The Course To field is used to indicate the highest
course for which a block of cruising levels is prescribed.

Source/Content: The Courses will be derived from official government sources in degrees and
tenths of degree with the decimal point suppressed. The Magnetic/True indicator field will be
used to indicate True (T) or Magnetic (M) courses. Used On: Cruising Table records

Length: 4 characters

Character Type: Numeric Examples: 0000, 1790, 3590
