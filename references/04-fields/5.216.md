# 5.216 Controlled Airspace Name

> 缩写 `ARSP NAME` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.25.1 列 94（Controlled Airspace Name）

## 定义

Definition/Description: The Controlled Airspace Name field will contain the name of the
controlled airspace when assigned.

Source/Content: Names will be derived from official government sources. The name, if assigned,
will be entered in the first record only. If source does not assign a name, the field may be
blank. Used On: Controlled Airspace records

Length: 30 characters

Character Type: Alpha/numeric Examples: DENVER CLASS B, OAKLAND OCTA
