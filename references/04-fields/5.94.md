# 5.94 True Bearing

> 缩写 `TRUE BRG` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.10.3 列 52（Runway True Bearing）；4.1.11.3 列 52（Localizer True Bearing）；4.1.22.2 列 102（Azimuth True Bearing）；4.1.22.2 列 96（Back Azimuth True Bearing）

## 定义

Definition/Description: The True Bearing field defines the true inbound course for ILS
localizer, MLS Azimuth, MLS Back Azimuth and facilities the true bearing for Runways.

Source/Content: True Bearings are entered into the field in degrees, tenths of a degree and
hundredths of a degree, with the decimal point suppressed. When source does not provide a true
bearing, the value will be derived, see Section 5.95 for source description. Used On: ILS
Continuation, MLS Continuation and Runway Continuation records

Length: 5 characters

Character Type: Numeric Examples: 19000, 23021, 06050
