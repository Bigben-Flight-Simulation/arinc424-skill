# 5.184 Communication Altitude

> 缩写 `COMM ALTITUDE` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.14.1 列 84（Communication Altitude 1）；4.1.14.1 列 87（Communication Altitude 2）；4.1.14.6 列 31（Additional Sectorization 1 Altitude 1）；4.1.14.6 列 34（Additional Sectorization 1 Altitude 2）；4.1.14.6 列 44（Additional Sectorization 2 Altitude 1）；4.1.14.6 列 47（Additional Sectorization 2 Altitude 2）；4.1.14.6 列 57（Additional Sectorization 3 Altitude 1）；4.1.14.6 列 60（Additional Sectorization 3 Altitude 2）；4.1.14.6 列 70（Additional Sectorization 4 Altitude 1）；4.1.14.6 列 73（Additional Sectorization 4 Altitude 2）；4.1.23.1 列 118（Communication Altitude 1）；4.1.23.1 列 121（Communication Altitude 2）；4.2.5.1 列 84（Communication Altitude 1）；4.2.5.1 列 87（Communication Altitude 2） 等 22 处

## 定义

Definition/Description: The Communications Altitude 1 and Altitude 2 fields are used to provide
information on use of communications services frequencies with reference to specific altitudes.
If the communications record in which Communications Altitude data is provided includes
Sectorization data (5.183), the altitude data is valid only for the specific Sector.

Source/Content: Communications Altitude information will be derived from official government
source documentation. The fields are to be processed in conjunction with the Communications
Altitude Description field. The field will contain altitude expressed in hundreds of feet. The
Communications Altitude 1 field will contain a value when the Communications Altitude
Description contains the character + (plus) or - (minus). The Communications Altitude 1 field
may contain a value when the Communications Altitude Description is blank, indicating that
communications service/frequency is used at a specific altitude only. The Communications
Altitude 1 and Altitude 2 fields will contain values when the Communications Altitude
Description contains the character B. Enroute, Airport, and Heliport Primary Communications Used
On: Records

Length: 3 characters

Character Type: Alpha/numeric Examples: 050 (5000 feet), 245 (24500 feet)
