# 5.91 Continuation Record Application Type

> 缩写 `APPL` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.10.2 列 23（Application Type）；4.1.10.3 列 23（Application Type）；4.1.11.2 列 23（Application Type）；4.1.11.3 列 23（Application Type）；4.1.13.2 列 23（Application Type）；4.1.14.2 列 23（Application Type）；4.1.14.3 列 23（Application Type）；4.1.14.4 列 23（Application Type）；4.1.14.5 列 23（Application Type）；4.1.14.6 列 23（Application Type）；4.1.15.2 列 23（Application Type）；4.1.17.2 列 21（Application Type）；4.1.18.2 列 26（Application Type）；4.1.18.3 列 26（Application Type） 等 80 处

## 定义

Definition/Description: This field indicates specific application of this continuation record.

Source/Content: The field will contain one of the following type codes: Used On: Continuation
Records

Length: 1 character

Character Type: Alpha

## 码表

> 取自 `arinc424-core` 的枚举，比正文表格更完整；变体名即语义。

**取值** — `ContinuationApplicationType`

| 代码 | 含义 |
|---|---|
| ` ` | Blank |
| `A` | Standard Arinc Continuation |

| `C` | Call Sign Or Controlling Agency Continuation |
| `E` | Primary Record Extension |
| `L` | Vhf Navaid Limitation Continuation |
| `N` | Sector Narrative Continuation |
| `T` | Time Of Operations Formatted |
| `U` | Time Of Operations Narrative |
| `V` | Time Of Operations Date Range |
| `P` | Flight Planning Continuation |
| `Q` | Flight Planning Primary Data Continuation |
| `S` | Simulation Application Continuation |
| `W` | Airport Procedure Sbas Authorization |
