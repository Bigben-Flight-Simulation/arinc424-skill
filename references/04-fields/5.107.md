# 5.107 ATA/IATA Designator

> 缩写 `ATA/IATA` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.7.1 列 14（ATA/IATA Designator）；4.2.1.1 列 14（ATA/IATA Designator）

## 定义

Definition/Description: The ATA/IATA field contains the Airport/Heliport ATA/IATA designator
code to which the data contained in the record relates.

Source/Content: The content of this field should be derived from IATA Reservations Manual Part
II, IATA Resolution 763/Location Identifiers. Used On: Airport and Heliport records

Length: 3 characters

Character Type: Alpha Examples: DEN, LHR, JFK
