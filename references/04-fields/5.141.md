# 5.141 Starting Latitude

> 定义于 424-19 424-20 424-21 424-22 424-23 ｜ 缺失于 424-18

**用于：** 4.1.19.1 列 14（Starting Latitude）

## 定义

Definition/Description: The Grid MORA Table will contain records describing the MORA for each
Latitude and Longitude block. Each record will contain thirty blocks and the Starting Latitude
field defines the lower left corner for the first block of each record.

Source/Content: The Starting Latitude will be determined when the record is assembled. Used On:
Grid Mora record

Length: 3 characters

Character Type: Alpha/numeric Examples: N00, N42, S20, S90
