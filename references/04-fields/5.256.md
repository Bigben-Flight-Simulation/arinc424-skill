# 5.256 Reference Path Data Selector

> 缩写 `REF PDS` ｜ 定义于 424-19 424-20 424-21 424-22 424-23 ｜ 缺失于 424-18

**用于：** 4.1.28.1 列 31（Reference Path Data Selector）；4.1.35.1 列 31（Reference Path Data Selector）；4.2.8.1 列 31（Reference Path Data Selector）

## 定义

Definition/Description: The Reference Path Data Selector field enables the automatic tuning of a
procedure by Ground Based Augmentation Systems (GBAS) avionics. This data is not used for SBAS
operations.

Source/Content: A number from 00 to 48. Values 0-48 are selected via receiver channeling. The
field is set to zero for SBAS Path Point Records. Used On: Airport, Helicopter Operations SBAS
Path Point Records, GBAS Path Point Records

Length: 2 characters

Character Type: Numeric
