# 5.333 Location

> 缩写 `LOC` ｜ 定义于 424-23 ｜ 缺失于 424-18 424-19 424-20 424-21 424-22

**用于：** 4.1.37.1 列 42（Location Identifier）

## 定义

Definition/Description: In Fixed Network Addressing Domains, the purpose of the LOC field is to
distinguish Routing Areas within the same Routing Domain. In Mobile Network Addressing Domains,
the LOC field is used to distinguish Routing Areas within the same Mobile Routing Domain, or,
when more than one Routing Domain is located on a single Aircraft, to distinguish each Routing
Domain and the Routing Areas contained within them.

Source/Content: The field will be coded from either State publication or from ICAO
documentation. Used On: ATN Data Code Primary Records
