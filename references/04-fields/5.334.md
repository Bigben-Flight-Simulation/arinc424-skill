# 5.334 System Identifier

> 缩写 `SYS` ｜ 定义于 424-23 ｜ 缺失于 424-18 424-19 424-20 424-21 424-22

**用于：** 4.1.37.1 列 46（System Identifier）

## 定义

Definition/Description: ISO/IEC 10589 defines the System Identifier as a variable length field
which uniquely identifies an End or Intermediate System within an ISO/IEC 10589 Routing Area.
Within a Routing Area, all System Identifiers are of the same length, although a Router is not
able to make assumptions about the length of this field outside of its own Routing Area.

Source/Content: The field will be coded from either State publication or from ICAO
documentation. The field shall be right aligned and filled with the character 0 from the left.
Used On: ATN Data Code Primary Records

Length: 12 characters

Character Type: Alpha/numeric Examples: 45532D524D53, 000045533031
