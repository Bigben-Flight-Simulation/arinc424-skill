# 5.41 Region Code

> 缩写 `REGN CODE` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.4.1 列 7（Region Code）；4.1.5.1 列 7（Region Code）

## 定义

Definition/Description: The Region Code permits the categorization of waypoints and holding
patterns as either enroute or terminal area waypoints. In the latter case, the terminal area
airport is identified in the field.

Source/Content: The field contains the alpha characters ENRT for enroute waypoints and airport
identification code (Airport Ident) for terminal waypoints. In the holding pattern file, the
content will match that of the holding fix, e.g., if the holding fix is an enroute waypoint or
enroute Navaid, the content with be ENRT; if the holding fix is a terminal waypoint or terminal
NDB, the content will be the airport identification. Used On: Waypoint and Holding Pattern
records

Length: 4 characters

Character Type: Alpha/numeric Examples: ENRT, KLAX, 9V9
