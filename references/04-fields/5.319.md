# 5.319 Landing Threshold Elevation Accuracy Compliance Flag

> 定义于 424-22 424-23 ｜ 缺失于 424-18 424-19 424-20 424-21

**用于：** 4.1.10.1 列 100（Landing Threshold Elevation Accuracy Compliance Flag）

## 定义

Definition/Description: Flag that indicates if the Runway Landing Threshold Elevation meets
Accuracy Requirements defined as follows: Difference between Runway Landing Threshold Elevation
(A424 PG 5.68) and runway landing threshold elevation measured with an independent means is 5
meters or less.

Source/Content: The field will be populated by the data provider, using one of the three
possibilities presented in the below table: Used On: Runway Record

Length: 1 Character

Character Type: Alpha

## 正文表格

（424-23 第 321 页）

| Field Content Description |
|---|
| Y Landing Threshold Elevation data meets Accuracy Requirements |
| N Landing Threshold Elevation data does not meet Accuracy Requirements |
| Blank Landing Threshold Elevation data has not been evaluated against Accuracy Requirements |
