# 5.287 Type Recognized By

> 缩写 `TRB` ｜ 定义于 424-19 424-20 424-21 424-22 424-23 ｜ 缺失于 424-18

**用于：** 4.1.34 列 10（Type Recognized By）

## 定义

Definition/Description: The Type Recognized By field is used to provide an indication of the
provider of a given Communications Type (5.101).

Source/Content: The field content will be derived from the official government source used to
establish the Communications Type and will be selected from the table below: Used On:
Communications Type Translation Table Records

Length: 1 character

Character Type: Alpha
