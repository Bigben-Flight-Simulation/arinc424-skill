# 5.237 Procedure Description

> 缩写 `PROC DESC` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.27.1 列 86（Procedure Description）

## 定义

Definition/Description: The Procedure Description field used on Flight Planning
Arrival/Departure Data Records is the textual representation of the procedure name.

Source/Content: The Procedure Description will be derived from official government source. It
will assist in matching flight plan content to charted procedures. Used On: Flight Planning
Arrival/Departure Data Records

Length: 15 characters

Character Type: Alpha/numeric
