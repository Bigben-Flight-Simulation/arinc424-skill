# 5.89 Cost Index

> 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.12.1 列 88（Cost Index）；4.2.7.1 列 105（Cost Index）

## 定义

Definition/Description: The Cost Index field is used to define the relative value of fuel-
related costs and time-related costs for a particular route.

Source/Content: Source will be by customer airline. Used On: Company Route, Helicopter
Operations Company Route Records

Length: 3 characters

Character Type: Numeric Examples: 001, 011, 999
