# 5.223 Operation Type

> 缩写 `OPS TYPE` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.28.1 列 25（Operation Type）；4.1.35.1 列 25（Operations Type）；4.2.8.1 列 25（Operation Type）

## 定义

Definition/Description: The Operation Type field indicates whether the operation is an approach
procedure, an advanced operation or other operational to be defined later. COMMENTARY Advanced
operation can be straight-in approaches followed by a missed approach, a precision curved
approach or departure procedures and roll-out and taxiing procedures .

Source/Content: This field should contain a value in the range of 0 to 15, defined as follows:
Used On: Airport and Helicopter Operations SBAS Path Point Records, GBAS Path Point Records

Length: 2 characters

Character Type: Numeric

## 正文表格

（424-23 第 283 页）

| SBAS |
|---|
| 0 Straight-in or point-in-space approach procedure |
| 1-2 Reserved for future definition |
| 3-15 | Spare |
| GBAS |
| 0 Straight-in approach | path |
| 1 Terminal Area Path definition (not for FAS Datablock) |
| 2 Missed Approach (not for FAS Datablock) |
| 3-15 | Spare |
