# 5.305 Heliport Type

> 定义于 424-21 424-22 424-23 ｜ 缺失于 424-18 424-19 424-20

**用于：** 4.2.1.1 列 32（Heliport Type）

## 定义

Definition/Description: This field provides information on the type of heliport facility.

Source/Content: The indicator will be selected from the table below. Used On: Heliport Records

Length: 1 Character

Character Type: Alpha (may be blank)

## 正文表格

（424-23 第 316 页）

| Heliport Type Field | Content |
|---|---|
| Hospital | H |
| Oil Rig | O |
| All other types | Blank |
| Type not provided | U |
