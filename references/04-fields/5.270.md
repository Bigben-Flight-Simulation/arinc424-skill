# 5.270 TCH Value Indicator

> 缩写 `TCHVI` ｜ 定义于 424-19 424-20 424-21 424-22 424-23 ｜ 缺失于 424-18

**用于：** 4.1.10.1 列 81（TCH Value Indicator）

## 定义

Definition/Description: The TCH Value Indicator field will define which TCH value is provided in
the runway record.

Source/Content: The field will contain a value from the following table: Used On: Runway Records

Length: 1 character

Character Type: Alpha

## 码表

> 取自 `arinc424-core` 的枚举，比正文表格更完整；变体名即语义。

**取值** — `TchValueIndicatorItem`

| 代码 | 含义 |
|---|---|
| ` ` | Blank |
| `I` | Ils Or Mls Glide Slope |
| `R` | Rnav Procedure |
| `V` | Vgsi |
| `D` | Default Fifty Feet |
