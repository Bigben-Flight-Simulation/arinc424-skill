# 5.197 Modulation

> 缩写 `MODULN` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.15.1 列 85（Datum Code）；4.1.2.1 列 91（Datum Code）；4.1.29.1 列 103（Datum Code）；4.1.3.1 列 91（Datum Code）；4.1.32.1 列 91（Datum Code）；4.1.4.1 列 85（Datum Code）；4.1.7.1 列 87（Datum Code）；4.2.1.1 列 28（Datum Code）；4.2.2.1 列 85（Datum Code）

## 定义

Definition/Description: The Modulation field will design the type of modulation for the
frequency in the Communication Frequency (5.103) field.

Source/Content: The field contains the following information: The field will be set to A unless
the source documentation specifies otherwise. Used On: Enroute, Airport, and Heliport
Communication Records

Length: 1 character

Character Type: Alpha
