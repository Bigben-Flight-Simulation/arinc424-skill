# 5.162 Step Climb Indicator

> 缩写 `STEP` ｜ 定义于 424-18 424-20 424-21 424-22 424-23 ｜ 缺失于 424-19

## 定义

Definition/Description: The Step Climb Indicator field is used to indicate if step climb up or
down is permitted.

Source/Content: Used On: Airway Restriction and Airway Restriction Continuation records

Length: 1 character

Character Type: Alpha

## 正文表格

（424-23 第 255 页）

| Field Content Description |
|---|
| B Step climb up or down is permitted |
| D Only step climb down is permitted |
| N No step climb is permitted |
| U Only step climb up is permitted |
