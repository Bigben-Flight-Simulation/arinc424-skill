# 5.124 FIR/UIR Entry Report

> 缩写 `ENTRY` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.17.1 列 31（Entry Report）

## 定义

Definition/Description: The FIR/UIR Entry Report field is used to indicate whether an entry
report on ICAO flight plan is required for that specific FIR/UIR.

Source/Content: FIR/UIR Entry Report should be derived from official government publications. Y
in this field indicates Entry Report is required, N in this field indicates no Entry Report is
required. The field will be entered on the first record only for each FIR/UIR identifier. Used
On: FIR/UIR records

Length: 1 character

Character Type: Alpha
