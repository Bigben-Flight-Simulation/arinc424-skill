# 5.226 Glide Path Angle

> 缩写 `GPA` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.28.1 列 67（Glide Path Angle）；4.1.35.1 列 67（Glide Path Angle）；4.2.8.1 列 67（Glide Path Angle）

## 定义

Definition/Description: The Glide Path Angle field is an angle, expressed in degrees, tenths and
hundredths of degrees, measured at the Flight Path Control Point (FPCP) of those approach
procedures that require the coding of an Airport or Helicopter Operations SBAS Path Point record
or GBAS Path Point Record. It establishes the intended descent gradient for the final approach
flight path. For an illustration of the GPA and related points, see

Figure 5-8.

Source/Content: The values will be derived from official government source. Used On: Airport and
Helicopter Operations SBAS Path Point Record, GBAS Path Point Records

Length: 4 characters

Character Type: Numeric Examples: 0275 (is equal to 2.75°), 1015 (is equal to 10.15°), 0300 (is
3.00°) equal to Also, Fictitious Threshold Point (FTP) when used on Point in Space
