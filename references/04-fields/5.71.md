# 5.71 Name Field

> 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.15.1 列 94（Marker Name）；4.1.2.1 列 94（VOR Name）；4.1.3.1 列 94（NDB Name）；4.1.32.1 列 94（TACAN Name）；4.1.7.1 列 94（Airport Name）；4.2.1.1 列 94（Heliport Name）

## 定义

Definition/Description: This field will be used to further define the record by name.

Source/Content: Facility name will be derived from official government sources. A parenthetical
name following the official name may be used to identify the location of the facility. Used On:
Navaid, Airport, Heliport and Enroute Marker records

Length: 30 characters

Character Type: Alpha/numeric
