# 5.82 Waypoint Usage

> 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.4.1 列 31（Waypoint Usage）；4.2.2.1 列 31（Waypoint Usage）

## 定义

Definition/Description: The waypoint usage field is employed to indicate the structure in which
the waypoint is utilized.

Source/Content: Used On: Waypoint (EA/PC) and Heliport Terminal Waypoint (HC) records

Length: 1 character

Character Type: Alpha

## 码表

> 取自 `arinc424-core` 的枚举，比正文表格更完整；变体名即语义。

**取值** — `WaypointUsageCol31`

| 代码 | 含义 |
|---|---|
| `B` | High And Low Altitude |
| `H` | High Altitude |
| `L` | Low Altitude |
| ` ` | Terminal Use Only |

**取值** — `WaypointUsageRnav`

| 代码 | 含义 |
|---|---|
| ` ` | Blank |
| `R` | Rnav |

## 正文表格

（424-23 第 218 页）

| Usage Record Column | Content |
|---|---|
| 31 |
| HI and LO Altitude | B |
| HI Altitude | H |
| LO Altitude | L |
| Terminal Use Only (not used enroute) | Blank |
