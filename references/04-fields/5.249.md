# 5.249 Surface Code

> 缩写 `SC` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.10.2 列 97（Runway Surface Code）；4.1.36.1 列 52（Helipad Surface Code）；4.1.7.1 列 32（Longest Runway Surface Code）；4.2.9.1 列 52（Helipad Surface Code）

## 定义

Definition/Description: On Airport Records, the Longest Runway Surface Code field is used to
define whether there is a hard surface runway at the airport, the length of which is indicated
in the Longest Runway field. On Runways Continuation Records, the Runway Surface Code field is
used to define whether the runway described in the record is a hard surface, soft surface,
runway. or water On Helipad Records, the Helipad Surface Code field is used to define whether
the helipad described in the record is a hard surface, helipad. soft surface, or water

Source/Content: The content will be selected from the table below. Used On: Airport Records
Runway Continuation Record, Airport, and Heliport Helipad Records

Length: 1 character

Character Type: Alpha
