# 5.288 Translation

> 定义于 424-19 424-20 424-21 424-22 424-23 ｜ 缺失于 424-18

**用于：** 4.1.34 列 11（Translation）

## 定义

Definition/Description: The Translation field is used to provide a decoding of a three-
character Communications Type (Section 5.101).

Source/Content: The content of the field will be derived from official government source
documentation. There will be a listing for every Communications Type contained in the output
file. Used On: Communications Type Translation Table Records

Length: 80 characters max

Character Type: Alpha/numeric Examples: TWR: ATC Control Tower GCO: Ground Communication Outlet
ATI: Automated Terminal Services
