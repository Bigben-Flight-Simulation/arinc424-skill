# 5.44 Localizer/MLS/GLS Identifier

> 缩写 `LOC, MLS, GLS IDENT` ｜ 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.11.1 列 14（Localizer Identifier）；4.1.13.1 列 14（Localizer Identifier）；4.1.22.1 列 14（MLS Identifier）；4.1.29.1 列 14（GLS Ref Path Identifier）

## 定义

Definition/Description: The Localizer/MLS/GLS Identifier field identifies the localizer, MLS
facility or GLS Ref Path defined in the record.

Source/Content: The field contains the identification code of the Localizer or MLS facility or
GLS Reference Path derived from official government sources. Used On: Localizer, Localizer
Marker, MLS, MLS Continuation, and GLS Record.

Length: 4 characters max

Character Type: Alpha/numeric Examples: Localizer - IDEN, ISTX, IDU, PP MLS - MDEN, MSTX, MLAX
GLS - LFBL, EGLC, KSAN
