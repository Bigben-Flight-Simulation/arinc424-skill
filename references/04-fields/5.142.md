# 5.142 Starting Longitude

> 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.19.1 列 17（Starting Longitude）

## 定义

Definition/Description: The Grid MORA table will contain records describing the MORA for each
Latitude and Longitude block. Each record will contain thirty blocks and the Starting Longitude
field defines the lower left corner for the first block of each record.

Source/Content: The Starting Longitude will be determined when the record is assembled. Used On:
Grid Mora records

Length: 4 characters

Character Type: Alpha/numeric Examples: E000, W150, E090, W180
