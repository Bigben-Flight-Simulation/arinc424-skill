# 5.126 Restrictive Airspace Name

> 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.18.1 列 94（Restrictive Airspace Name）；4.1.33.1 列 94（Special Activity Area Name）

## 定义

Definition/Description: The Restrictive Airspace Name field will contain the name of the
restrictive airspace when assigned.

Source/Content: Names will be derived from official government sources. The name, if assigned,
will be entered in the first record only. If source does not assign a name, this field may be
blank. Used On: Restrictive Airspace records and Special Activity Area records

Length: 30 characters

Character Type: Alpha/numeric Examples: RANDOLPH ONE MOA, SAMBURU GAME RESERVE
