# 5.158 VFR Checkpoint Flag

> 定义于 424-18 424-19 424-20 424-21 424-22 424-23

**用于：** 4.1.2.1 列 119（VFR Checkpoint Flag）；4.1.3.1 列 80（VFR Checkpoint Flag）；4.1.4.1 列 80（VFR Checkpoint Flag）；4.1.7.1 列 90（VFR Checkpoint Flag）

## 定义

Definition/Description: The VFR Checkpoint field indicates whether this fix is a VFR Checkpoint
or VFR Reporting Point (VRP).

Source/Content: The VFR Checkpoint will be derived from official government source. When the fix
is designated as a VFR Checkpoint or VRP, the value will be "Y" (Yes). Otherwise, the value will
be blank. Used On: VHF Navaid, NDB Navaid, Terminal NDB Navaid, Enroute Waypoints, Airport
Terminal Waypoints, Heliport Terminal Waypoints, Airport

Length:

Character Type: Alpha/numeric
