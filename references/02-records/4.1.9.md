## 4.1.9.6 Airport SID/STAR/Approach Procedure Name Continuation Record

The Airport SID/STAR/Approach Name Continuation Record contains the textual representation of
the SID/STAR/Approach full procedure name as described in Section 5.139 of this document. For
SID and STAR procedures having a common portion (Route Type 2), this Continuation Record is
provided for the first record of the route type 2 coding. For SID and STAR procedures having no
common portion (Route Type 2), this Continuation Record is provided for the first record of each
runway transition. For approach procedures, this Continuation Record is provided once per
procedure as a Continuation to the first record of the final approach coding.
